El modelo lógico completo

(U) = propiedad única · ? = opcional · [a / b] = cardinalidad: destinos por cada origen / orígenes por cada destino · gris: contenido · naranja: ejecución · verde: resultados

Este es el diagrama del modelo lógico. Cada caja es una etiqueta de nodo con sus propiedades; cada flecha es una relación con su nombre y sus cardinalidades. Las cinco consultas se resuelven recorriendo entre tres y siete relaciones de este diagrama. Es coherente con el diccionario de entidades, el catálogo de relaciones y la tabla de cardinalidades.
