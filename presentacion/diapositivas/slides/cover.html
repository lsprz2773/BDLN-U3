QATO’K

Modelo lógico de una plataforma de simulaciones profesionales, sobre una base de datos orientada a grafos

Neo4j como base principal · PostgreSQL como complementaria

Presentamos QATO’K: una plataforma para practicar situaciones laborales mediante simulaciones. Hoy mostramos la idea, los siete entregables del modelo lógico y por qué la propuesta encaja en una base de datos orientada a grafos.
